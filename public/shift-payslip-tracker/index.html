Import into Google Sheets

  1. Download the .xlsx file. On a computer, sign in to Google Sheets and open a blank spreadsheet.
  2. Choose File → Import → Upload and select the .xlsx file. Under Import location, select Create new spreadsheet. Click Import data and open the new spreadsheet.
  3. Choose File → Settings. Set Locale to United Kingdom, then click Save settings. This lets you enter dates as DD/MM/YYYY.
  4. Rename the new spreadsheet and open Start Here. This is your editable copy. To keep a blank spare, choose File → Make a copy before entering shifts.

Good to know

  • Estimates are based on the rates you enter and cover hours and gross pay before deductions.
  • Set your hourly rates once on Start Here — changing them updates earlier estimates.
  • Overnight shifts count in full on their start date.
